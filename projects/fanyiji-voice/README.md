# 翻译姬·语音版

独立语音字幕项目，没有 Chrome 原生字幕模式或切换按钮。

## 功能

- 麦克风、电脑声音及指定内置浏览器声源采集，未开启的通道不显示。
- SenseVoice + Silero VAD；GTCRN 语音增强、UVR 伴奏分离。
- 本地翻译、Codex CLI、本地暂译 + CLI 终稿、Google / 有道网页翻译、国内 CLI。
- 中日双向翻译，模型下载／导入、专用模型数据与训练准备。
- 简体中文、日文、英文界面；默认字幕 16 号、透明度 66%。
- 本机管理员原有内置浏览器弹幕、失败句处理及词规则管理。

直接打开完整程序目录中的 **翻译姬·语音版.exe**，不能只复制 EXE。
离线使用需要预先下载模型并选择本地翻译；CLI／网页翻译仍需网络及对应账号。
独立资料目录：`%LOCALAPPDATA%\FanyiJiVoice`。
专用覆盖变量：`FANYIJI_VOICE_DATA`、`FANYIJI_VOICE_MODELS`。

## 打包

```powershell
python tools/prepare_llama_runtime.py
python tools/build.py
```

已有 CPU / CUDA 原生运行库时可传 `python tools/build.py --llama-runtime <目录>`。
输出 `dist/翻译姬·语音版/`，保留 NVIDIA GPU 运行库，不包含模型权重。

## 资料隔离

首次正常启动会复制旧设置、词规则、相关浏览器资料和失败句历史，保留原目录。
待发队列和统计重新开始；两版配置、日志、队列、单实例锁及浏览器资料互不共用。
已下载权重通过 `models-location.json` 复用，未复制或加入程序包。
新电脑默认模型目录为 `%LOCALAPPDATA%\FanyiJiModels\models`。
源码和程序包均不包含账号、Cookie、本机管理员授权或模型权重。
公开发行包的弹幕功能仍遵守现有本机管理员授权，未向外开放。
启动不会自动打开直播间。

## 翻译模型下载与导入

模型权重不是 EXE，不随程序包分发。下载成功不代表当前翻译源已经切换；
本地翻译权重只在 **本地翻译** 或 **本地暂译 + CLI 终稿** 模式下使用。
单独使用 Codex CLI、Google、有道或其他在线翻译源时，不会使用已下载的本地翻译权重。

在“模型管理”选择模型的“下载 / 续传”。中断后保留 `.part` 文件；再次点击可以续传。
下载会对照固定版本的大小与 SHA-256，失败详情显示网络、HTTP 或文件校验等具体原因。
请保留完整错误文字，以便区分网络问题和模型文件问题；无需提供 Cookie 或其他凭证。

浏览器直链下载完成后的使用步骤：

1. 保留完整的 `.gguf` 文件，GGUF 不需要解压。`.part`、`.crdownload` 是未完成下载，不能导入；网页或链接文件也不是模型。
2. 回到“模型管理”，点击唯一的顶部 **导入本地模型 → 选择 ZIP / 模型文件**，直接从下载目录选择该 `.gguf`，无需先手动移进模型目录；导入会自动安排保存路径。ZIP 或完整模型文件夹也可通过同一个按钮导入。
3. 确认翻译模型用途、兼容模板和自定义显示名称，点击 **校验并导入**。导入会复制文件到独立模型目录，保留原下载文件，因此目标磁盘需要额外容纳一份同等大小的模型。
4. 在“更改设置”选择本地翻译或本地暂译 + CLI 终稿；回到“模型管理”，选中导入的模型，确认 SenseVoice、VAD 及已开启的声音筛选依赖就绪，点击 **使用选中模型**。

“打开模型目录”可打开实际保存位置，“手动下载使用说明”随时可查看上述步骤。
各模型的“离线放置说明”还提供该预设版本的完整路径、文件名、大小和 SHA-256；
如果选择手动复制，必须全部匹配，再点击“重新校验本地文件”，最后手动启用。
优先使用程序模型目录列出的 GGUF 版本；其他 GGUF 可自定义导入，但文件后缀相同不保证运行兼容或翻译效果。

界面下载直链提供已核验版本的官方下载来源。无论使用浏览器还是程序下载，都不要把模型文件放进 EXE 的 `_internal` 目录；
更新或重新打包程序不会改动独立模型目录。

## 源码运行

使用 Python 3.12，当前项目可独立安装，不需要父目录或另一个项目。
两个项目应各自使用虚拟环境；不要把两套可编辑源码安装进同一个环境。

```powershell
python -m pip install -e ".[dev]"
python run.py
python -m pytest -q
```

`python run.py --smoke-test` 只检查界面，不采集声音、不打开浏览器、不写设置。
兼容旧 `FANYIJI_*` / `LOCAL_SUBTITLES_*` 环境变量；同时运行两版应使用各自专用变量。
显式 DATA 覆盖时不会导入旧账号资料。
